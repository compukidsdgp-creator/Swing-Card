# Inbox — start a new batch here

1. Upload the new SwingScope batch HTML into this folder (GitHub: **Add file → Upload files**).
2. Optional: also upload your research notes as a `.txt` with the **same name** as the HTML,
   or named `research_notes_<batch date>.txt` (e.g. `research_notes_2026-10-27.txt`).
3. Commit. The Action runs automatically, registers the batch, sends a Day-0 message to Telegram
   (on the signal day) and moves the files to `inbox/processed/`.

From then on the batch is tracked every day at 18:05 IST until Day 21. Old batches stop on their own.
You can upload notes for an existing batch any time with the `research_notes_<batch date>.txt` name.
